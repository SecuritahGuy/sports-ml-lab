## Promotion Policy

- A challenger must beat incumbent on **both** rolling validation and final holdout with Δ ≥ 0.001.
- Selection is by rolling-origin 3-fold average val LL, not single-season holdout.
- Platt calibration is fit per fold, not once on all historical data.
- No model change without documented experiment, test suite, and registry update.

## Rollback Procedure

If a weekly prediction must be rolled back:

1. **Identify offending snapshot**: Check `reports/predictions/snapshot_manifest.json` for the snapshot timestamp and mode.
2. **Keep the failed snapshot**: Move to `reports/predictions/snapshots/failed/` with a note file explaining why.
3. **Rerun with corrected inputs**: Fix the QB input CSV or other issue, then re-run `predict-week`.
4. **Update manifest**: The new snapshot will be added to the manifest with a new timestamp.
5. **Notify**: Add operator note in the weekly monitoring report explaining the rollback and cause.
6. **Do not delete old snapshots**: Historical audit trail must be preserved.
