# Regularized Logistic Meta-Model Experiment

## Research Question

Can a more regularized logistic layer improve on v3.0.0 Frozen QB Overlay by tuning C/penalty and adding a tiny set of low-risk pregame features?

## Architecture

```
For each rolling-origin fold:
  1. Fit fold-safe incumbent (Platt + QB overlay) on train seasons
  2. Compute meta-input = logit(v3.0.0 incumbent prob)
  3. Build meta-features = [meta-input] + optional small feature group
  4. Fit regularized logistic meta-model on train seasons only
  5. Score meta-model on validation season
```

Feature groups are tested separately to isolate each signal.

## Hyperparameter Grid

- L2 (lbfgs): C in [0.01, 0.03, 0.1, 0.3, 1.0, 3.0]
- L1 (saga): C in [0.01, 0.03, 0.1, 0.3, 1.0, 3.0]
- ElasticNet (saga): C in [0.01, 0.03, 0.1, 0.3, 1.0, 3.0] × l1_ratio in [0.25, 0.5, 0.75]
Per feature set: 30 variants (6 L2 + 6 L1 + 18 EN)
Total: 150

## No-Go Columns

The following column types are explicitly excluded from all feature sets:
- Market: moneyline, spread, odds, no-vig probability
- Score/result: home_score, away_score, result, home_win
- Target: is_tie
