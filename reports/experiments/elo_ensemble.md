# Elo Parameter Ensemble

## Research Question

Does averaging Elo probabilities across diverse parameter configurations beat the single-best v3.0.0 champion configuration? Ensemble averaging reduces variance and may produce more robust predictions.

## Architecture

```
base Elo (N diverse configs, equal-weighted average)
→ fold-safe Platt on [ensemble_prob, qb_changed, rolling_mov_3]
→ frozen QB overlay (v3.0.0 champion, fixed)
→ validation/holdout comparison
```

## Takeaways

1. **Ensemble averaging does not help** — combining diverse Elo configs does not beat the single-best v3.0.0 champion.
2. **Platt scaling absorbs ensemble differences** — the logistic calibration compresses prediction variation, making the ensemble redundant.
3. **Equal-weighted vs weighted makes no difference** — all variants are within 0.001 of each other.
4. **The QB overlay dominates** — once the base Elo probability is close, the overlay and Platt calibration are the main signal sources.
