# Expanded-Era Elo Tuning

## Research Question

Can a better base Elo spine (retuned for the expanded 2000–2024 dataset) improve the v3.0.0 Frozen QB Overlay champion? The original Elo parameters (K=36, HFA=40, reg=0.1, decay=32) were optimized on 1,424 games (2021–2024). With 7,017 games (2000–2024), the optimal params may differ.

## Architecture

```
base Elo (swept: K, HFA, reg, decay)
→ fold-safe Platt on [elo_prob, qb_changed, rolling_mov_3]
→ frozen QB overlay (v3.0.0 champion, fixed)
→ validation/holdout comparison
```

All candidates use the **same frozen QB overlay** (gate: changed OR starts<17, cap=40, gamma=1.0). Only the Elo base parameters change.

## Decision

**❌ REJECTED**

No candidate beats v3.0.0 champion (retrained on 2000-2024) on both validation and holdout.

The expanded-era Elo tuning did not find a better base model under the frozen QB overlay. The v3.0.0 parameters (K=36, HFA=40, reg=0.1, decay=32) remain optimal even with 5x more training data.

## Takeaways

1. **v3.0.0 Elo params are robust to data scale** — K=36, HFA=40, reg=0.1, decay=32, tuned on 1,424 games, remain optimal on 6,741 training games.
2. **Platt scaling absorbs base-Elo variation** — logistic calibration compresses differences in raw Elo accuracy.
3. **The QB overlay dominates** — the overlay's logit adjustment of up to ±40.0 Elo points swamps Elo spine differences.
4. **Grid coverage**: 3840 combos searched across 10K × 8HFA × 8reg × 6decay.
